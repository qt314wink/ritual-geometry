02 / component architecture

Fork no physics.
Fork no path truth.

Each front door has a distinct root object, but all consuming code meets the same schema, coordinate transform, dated material profile, and violation contract. This is the seam that lets A be simple, B be a catalog, and C be a compiler without corrupting one another.

03 / specs & flows

Each surface has a different promise.

These are bounded product specifications, not a disguised mandate to cram every backend into a single app. The stated behaviors map to testable outputs and explicit exclusions.

A · Artifact maker

Wayfinder Studio

A clear single-canvas workspace for printing, a first cut, and an honest export receipt.

Inputs
Family view, Letter/A4, coloring/stencil, dated profile, guide state.
Outputs
PDF, closed SVG, optional GCode, `ExportReceipt`.
Definition of done
Margins, closed paths, profile/date, transform receipt, overlay under budget.
Choose motif→Set view→Export→Test corner

B · Family language

Ritual Geometry OS

A world for related motifs, derivation, remix lineage, workshop packs, and registered stacks.

Inputs
Family/version, master paths, layer count, discrete model chip, operators.
Outputs
Views, pack, layer plan, QA receipt, lineage record.
Definition of done
Three families × three views; cardboard release; ModeField and packing fixtures.
Open family→Derive views→Stack/test→Release

C · Machine gate

Latticeworks

A staged job compiler that makes unsafe or unsupported transformations visible, remediable, and blocking.

Inputs
Family pack/SVG or PIO JSON, material/profile, backend selection.
Outputs
Stage receipt, `Violation[]`, validated SVG/GCode; later WIF.
Definition of done
Bad bridge blocks emit; no silent substitutions; Stage 6 audit is mandatory.
Ingest→Resolve→Audit→Emit or block

05 / review protocol

Ten lenses with real vetoes.

Personas are a disciplined review procedure, not fictional authority. Each one must state a question, constraint, failure mode, and decision in a traceable decision record. Safety and evidence vetoes are not overridable by release enthusiasm.

Export truthEngineer

One transform governs preview and emitter. Veto a file that cannot prove its coordinates.

System seamsSystems architect

Protect bounded contexts. A remix may not mutate GCode directly.

Agency metricFeedback analyst

Track actual prints, tests, stacks, and re-use—not generated taste.

User languageCompassionate communicator

Make an attainable week clear; refuse false identity promises.

Pilot designInnovative inventor

Every release hypothesis gets a room, material, and kill criterion.

Motion lessonVisual architect

Movement teaches registration or change, never performs mysticism.

Fabrication vetoConstraint officer

Own the first physical failure: bridges, islands, kerf, and material tests.

Family integrityCatalog librarian

Own IDs, suffixes, versions, and lineage. Reject anonymous output.

Cheap practiceCurriculum designer

Design reversible cardboard/paper mistakes before expensive material.

Claim labelEpistemic QA auditor

Separate computed, observed, proposed, and unknown. Block unsupported physical claims.

Closure
